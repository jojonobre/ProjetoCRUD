## Sobre o Projeto

O **Sistema de Catálogo de Filmes** é uma aplicação web que permite aos usuários criar uma conta, realizar login, pesquisar filmes utilizando a **OMDb API**, favoritar títulos, atribuir avaliações, adicionar comentários e gerenciar seu perfil.

Além da experiência do usuário, o projeto conta com um **Painel Administrativo**, permitindo o gerenciamento dos usuários cadastrados.

O desenvolvimento teve como foco a prática de **JavaScript**, manipulação do DOM, consumo de APIs REST e persistência de dados utilizando **LocalStorage**.

---

## Funcionalidades

### Usuários

* Cadastro de novos usuários
* Login com autenticação
* Edição do nome do usuário
* Logout

### Filmes

* Pesquisa de filmes pela OMDb API
* Exibição de pôster, gênero, ano e sinopse
* Adição de filmes aos favoritos
* Limite de favoritos por usuário
* Remoção de filmes favoritos

### Avaliações

* Avaliação dos filmes de 1 a 5 estrelas
* Comentários personalizados
* Exibição da média das avaliações dos usuários
* Exibição da nota do IMDb

### Painel Administrativo

* Login exclusivo para administrador
* Cadastro de usuários
* Listagem de usuários
* Pesquisa por nome
* Exclusão de usuários

## Como Executar

### Clone o repositório

```bash
git clone https://github.com/seu-usuario/catalogo-filmes.git
```

### Acesse a pasta

```bash
cd catalogo-filmes
```

### Execute o projeto

Como se trata de uma aplicação em **HTML, CSS e JavaScript puro**, basta abrir o arquivo **login.html** em seu navegador.

Ou utilize a extensão **Live Server** no Visual Studio Code para uma melhor experiência durante o desenvolvimento.

---

## API Utilizada

O projeto utiliza a API pública **OMDb API** para pesquisa e obtenção de informações sobre filmes.

Entre os dados exibidos estão:

* Poster
* Título
* Ano
* Gênero
* Sinopse
* Nota IMDb
